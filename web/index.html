Entrée 1 × 28 × 28

Écris une phrase : chaque mot devient un token, puis un vecteur.

Dessine un chiffre : le réseau se recalcule à chaque trait.

Entraînement poids aléatoires

Fais apprendre le réseau sur 1 437 vrais chiffres manuscrits. Après chaque époque, toutes les vues se mettent à jour : regarde les filtres se former et la prédiction devenir juste.

Vue réseau

Chaque rond est un neurone, chaque vignette un canal qui montre ce qu'il voit de ton dessin ; chaque flèche est une connexion. Plus un rond est lumineux, plus il est actif. Le nombre de nœuds est celui écrit dans le code (au-delà de 16, « ⋮ » résume la suite). Survole une colonne pour retrouver sa ligne de code. Et si ? Clique sur un nœud pour l'éteindre : tout ce qui suit est recalculé sans lui, jusqu'à la prédiction.

Vue blocs

Le trajet réel des données, de haut en bas. Deux boîtes côte à côte travaillent en parallèle ; une flèche qui contourne des boîtes est un raccourci (connexion résiduelle) ; ⊕ marque l'endroit où deux chemins s'additionnent ou se combinent.

Ce que le réseau imagine

On part d'une image noire et on la retouche jusqu'à ce que le réseau soit sûr d'y voir un 0, puis un 1, un 2… Avant l'entraînement c'est du bruit ; après, on voit ce qu'il a retenu de chaque chiffre. Refais-le après quelques époques pour comparer.

Vue 3D

Chaque plaque est la sortie d'une couche : une ligne par mot, une case par nombre de son vecteur (orange positif, bleu négatif). Les plaques s'empilent dans l'ordre du calcul, comme les couches de BERT. Fais glisser pour tourner ; survole une plaque pour retrouver sa ligne de code.
